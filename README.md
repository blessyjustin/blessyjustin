## 🚀 Featured Projects


### 💼 Job Finder Portal

A web-based job recruitment application developed using ASP.NET MVC to connect job seekers with employers through separate registration workflows and structured database operations.

- 👤 **Multi-Role Registration:** Separate registration workflows for Job Seekers and Employers.
- 🔐 **User Authentication:** Login functionality and user-specific workflows.
- 🏢 **Employer Management:** Maintain employer details and manage employer-related operations.
- 🔎 **Job Search:** Designed to help job seekers discover relevant employment opportunities.
- 🗄️ **Database Integration:** Microsoft SQL Server for structured data storage and management.
- ⚙️ **Stored Procedure-Based Operations:** Database operations implemented using SQL Server stored procedures and Entity Framework-generated methods.
- 🏗️ **MVC Architecture:** Organized application structure using Models, Views, and Controllers.
- 📝 **Form Handling and Validation:** Manage registration inputs and validate submitted information.

**Tech Stack:** C#, ASP.NET MVC, SQL Server, Entity Framework, SQL Server Stored Procedures, HTML, CSS

**Project Goal:** To build a practical recruitment platform that streamlines interactions between job seekers and employers while strengthening my skills in .NET web development and database management.



### 🛍️ Clothing E-commerce Website

A web-based clothing e-commerce application developed using ASP.NET Web Forms to organize clothing products into categories and subcategories, with separate user and administrator workflows.

- 👤 **User Management:** User registration and login functionality.
- 🔐 **Administrator Access:** Separate administrator registration and login workflows.
- 🗂️ **Category Management:** Organize clothing products into categories and subcategories.
- 👗 **Product Management:** Add and manage clothing products through the administrator interface.
- 🛒 **Product Listing:** Display products based on selected categories and subcategories.
- 🗄️ **Database Integration:** Store and retrieve user, category, subcategory, and product information using SQL Server.
- 🏗️ **Master Pages:** Reusable layouts for consistent design across multiple pages.
- ⚙️ **ADO.NET Integration:** Connect the ASP.NET application to SQL Server and perform database operations.

**Tech Stack:** C#, ASP.NET Web Forms, ADO.NET, Microsoft SQL Server, HTML, CSS, JavaScript

**Project Goal:** To develop a structured clothing e-commerce website while gaining practical experience in ASP.NET Web Forms, database connectivity, session management, and multi-user application development.
